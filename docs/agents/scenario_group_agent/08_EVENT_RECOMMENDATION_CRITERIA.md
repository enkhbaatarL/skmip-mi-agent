# Event 추천 기준 v1

## 구현 범위

선택한 Event와 함께 시나리오를 구성할 Event를 최대 2개 추천하기 위한 기준이다.
현재 추가된 것은 프롬프트, structured output, 후보 ID 필터 및 출력 검증 helper다.
추천 API, LLM 호출, RAG 검색, 요청 사용자별 DB 권한 조회, 색인 동기화는 아직 연결되지 않았다.
게시/삭제 필터를 적용하는 내부 샘플 export와 문서 변환은 [Event 검색 문서 구성](09_EVENT_SEARCH_DOCUMENTS.md)에 있다.
기존 Event 검색 및 시나리오 생성 동작은 변경하지 않는다.

## 책임

| Task | 구현/규칙 |
| --- | --- |
| 1-1 목적·입출력 | 기준 Event 1개와 검색 후보 → 우선순위순 0~2개 및 근거·조합 선정 이유 |
| 1-2 관련성 | direct / supply_chain / supply_demand / conflicting_outlook |
| 1-3 평가 기준 | 영향 경로, 기간 적합성, 추가 정보, 시나리오 질문, 중복 여부를 프롬프트로 판단 |
| 1-4 필수 제외 | service가 현재 DB와 요청 사용자 권한으로 확인한 eligible ID만 helper에 전달 |
| 1-5 중복 | 같은 사실 반복은 제외, 의미 있는 후속 변화·비교 가능한 상충 전망은 허용 |
| 1-6 최종 선정 | 최대 2개, ID 중복 금지, 두 추천 사이의 의미 중복도 평가, 적합 후보 없으면 빈 결과 |
| 1-7 평가 사례 | 아래는 합성 기준 사례이며, 실제 DB 사례 수집·담당자 검토는 후속 작업 |

발생 시점과 영향 기간을 구분한다. 기간 미확인은 unknown으로 남기고 임의의 최근 N일 필터나 날짜를
도입하지 않는다. 상충 전망의 주체·출처·기준 시점·전제조건을 보존하고 사실로 승격하거나 평균하지 않는다.
검색 유사도는 후보 수집 신호이며 최종 선정 점수 또는 발생 확률이 아니다.
structuredEvidence 추가는 선행 조건이 아니다.

## 연결 계약

1. service가 기준 Event와 검색 후보의 현재 상태·본문을 DB에서 조회한다.
2. 삭제되지 않았고 PUBLISHED이며 요청 사용자에게 허용되는 ID 집합을 서버에서 계산한다.
   client/LLM이 제공한 ID 집합이나 갱신 지연이 있는 벡터 메타데이터만으로 권한을 판단하지 않는다.
3. `prepare_event_recommendation_candidates`로 기준 Event·명시적 제외 ID·중복 ID를 제거한다.
   기준 Event 자체가 eligible ID에 없으면 오류로 종료한다.
4. `build_event_recommendation_user_prompt`에 정제된 후보와 명시적인 기준일을 전달한다.
   system prompt는 `EVENT_RECOMMENDATION_SYSTEM_PROMPT`, 출력 schema는 `EventRecommendationOutput`을 사용한다.
5. `validate_event_recommendation_output`에 LLM에 실제 전달한 기준 Event와 후보를 전달한다.
6. 운영 연결 시 반환 전 현재 게시/접근 상태를 재확인하고, 변경된 후보의 내용은 노출하지 않는다.

서버 검증은 후보 ID 소속·기준 Event/ID 중복 제외와 근거의 원문 포함 여부를 확인한다.
인용 구절은 서로 다른 필드에 걸쳐 합성할 수 없다. 원문 포함 검증은 인과관계나 의미적 정당성을
보장하지 않는다. 관련성·기간 판단·동일 사건 여부·환각 품질은 실제 사례로 별도 평가해야 한다.
Pydantic은 개수·ID 타입·enum·필수 설명을 검증한다. 잘못된 결과를 조용히 잘라내지 않고 호출 계층에서
오류를 처리하도록 한다. 후보가 없으면 LLM 호출을 생략하고 빈 결과를 구성할 수 있다.

## 합성 평가 사례

| 기준 Event | 후보 | 기대 판단 |
| --- | --- | --- |
| LNG 설비 가동 중단 | 같은 사고의 동일 내용 반복 | 제외: 추가 정보 없음 |
| LNG 설비 가동 중단 | 해당 설비의 복구 일정 변경 | 허용 가능: timing/recovery 불확실성 추가 |
| LNG 설비 가동 중단 | 같은 영향 기간의 유럽 재고 감소 | 허용 가능: 공급 부족과 재고 대응 경로 |
| LNG 설비 가동 중단 | 영향 연결 근거가 없는 다른 국가의 과거 뉴스 | 제외: 단어 유사성만 존재 |
| 기관 A의 수요 증가 전망 | 같은 대상·기간·전제의 기관 B 수요 감소 전망 | 허용 가능: 전망별 근거 보존 |
| LNG 설비 가동 중단 | 영향 기간이 불명확하나 대체 공급 경로가 설명된 Event | unknown 명시 후 추가 정보로 판단 |

실제 평가에서는 후보 검색 누락과 최종 선정 오류를 구분하고, 두 추천 사이의 중복 및 원문에 없는
인과 단정도 검토한다. 이 합성 사례는 추천 품질 검증 완료를 의미하지 않는다.
